# YouTube Trending Video Analytics

## Project Overview
This project analyzes YouTube trending videos using Python, Oracle SQL, and Tableau. The objective is to identify trending patterns, analyze viewer engagement, perform sentiment analysis, and create an interactive dashboard.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- TextBlob
- Oracle SQL
- Tableau

## Dataset
YouTube Trending Videos Dataset

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Feature Engineering
4. Sentiment Analysis
5. Exploratory Data Analysis
6. SQL Analysis
7. Tableau Dashboard
8. Business Insights

## Key Features
- Data Cleaning
- Sentiment Analysis
- Interactive Dashboard
- SQL Queries
- Data Visualization

## Dashboard KPIs
- Total Videos
- Total Views
- Average Likes
- Total Comments

## Business Insights
- Some categories consistently dominate trending videos.
- Higher views generally lead to higher likes and comments.
- Positive and neutral titles are more common.
- Trending activity varies across countries and months.
